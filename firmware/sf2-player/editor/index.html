SF2 PLAYER

Load a SoundFont, pick a preset, and play it from the keys, pads, MIDI or the DAW. The same instrument is available in the device's SOUND and FILES pages.

Sound

SoundFont

Fonts are parsed into one of two static 16 MB banks. The maximum file size is 16 MB. Uploads live in RAM; keep the .sf2 on media to reload it after a restart.

Media paths start with a source key shown in the device's FILES page. On the VIBE, fonts on the card or a USB stick appear there automatically; in the browser or plugin you can also drop an .sf2 onto the window.
